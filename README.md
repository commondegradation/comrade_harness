# Comrade Harness 2.0

Локальный десктопный «харнесс» для языковых моделей: агент работает в выбранной папке,
свободно ходит в интернет, показывает собственные размышления и может действовать в твоих
сервисах (GitHub, Notion, Slack, Gmail, Drive, Linear, Jira) через плагины.

Приложение собрано на Electron: одно и то же ядро работает на macOS и Windows.

---

## Что изменилось в этой версии

| Запрос | Что сделано |
| --- | --- |
| Нормальный выбор папки | Отдельное окно выбора рабочей папки: системный диалог, ручной ввод пути, история последних папок, быстрые ссылки, drag & drop папки прямо в окно |
| Видно, как модель размышляет | Живой блок «Размышление» с потоковым текстом (`reasoning_content`) прямо во время ответа; сворачивается автоматически, сохраняется в истории |
| Свободный доступ к сайтам | Три инструмента: `web_search` (живой поиск), `read_url` (быстрое чтение страницы), `browser` (настоящий Chromium: JavaScript, cookie, входы в аккаунты) |
| Ответ без «пузыря» | Сообщение ассистента — обычный текст на фоне чата, во всю ширину колонки; пузырь остался только у твоих сообщений |
| Несколько моделей у провайдера | У каждого провайдера список моделей, есть переключатель моделей, поиск, быстрые пресеты и загрузка списка моделей из API |
| Сборка под macOS и Windows | `dist/Comrade Harness-2.0.0-mac-arm64.dmg`, `.zip` и `dist/Comrade Harness-2.0.0-win-x64.zip` |
| MCP через плагины | Раздел «Плагины»: MCP-серверы (stdio и HTTP) с пресетами + готовые коннекторы сервисов, где пользователь логинится, а агент работает от его имени |

## Быстрый старт (режим разработки)

```bash
cd comrade-harness
npm install
npm start
```

При первом запуске:

1. Нажми на карточку рабочей папки в левом верхнем углу (или `Cmd/Ctrl+O`) и выбери папку —
   агент будет читать и писать файлы только внутри неё.
2. Перейди в «Провайдеры» → выбери пресет (OpenAI, DeepSeek, OpenRouter, Groq, Mistral, Gemini,
   xAI, Together, Ollama, LM Studio) → вставь API-ключ → «Загрузить из API» подтянет список моделей.
3. Вернись в чат и выбери модель в верхней панели (`Cmd/Ctrl+K`).

Горячие клавиши: `Cmd/Ctrl+N` — новый чат, `Cmd/Ctrl+K` — выбор модели, `Cmd/Ctrl+O` — выбор папки.

## Сборка приложений

```bash
npm run build:mac            # macOS (arm64): .dmg + .zip
npm run build:win            # Windows x64: портативная сборка .zip
npm run build:win:installer  # Windows x64: установщик .exe (NSIS)
npm run build:all            # macOS + Windows (zip)
```

Готовые файлы появляются в `dist/`:

| Файл | Что это |
| --- | --- |
| `Comrade Harness-2.0.0-mac-arm64.dmg` | образ для macOS (Apple Silicon) с ярлыком «Программы» |
| `Comrade Harness-2.0.0-mac-arm64.zip` | то же приложение архивом |
| `Comrade-Harness-Setup-2.0.0-x64.exe` | установщик для Windows x64 |
| `Comrade Harness-2.0.0-win-x64.zip` | портативная сборка для Windows x64 |

macOS-сборка подписывается ad-hoc подписью автоматически (`scripts/after-pack.js`): без этого
изменённый после упаковки бандл не запускается на Apple Silicon.

### Установка на macOS

1. Открой `Comrade Harness-2.0.0-mac-arm64.dmg`, перетащи приложение в «Программы».
2. Сборка не подписана сертификатом Apple, поэтому при первом запуске:
   правый клик по приложению → «Открыть» → «Открыть».
   Если система всё равно ругается, сними карантин:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Comrade Harness.app"
   ```
   Сборка только для Apple Silicon (arm64).

### Установка на Windows (x64)

Вариант с установщиком: запусти `Comrade-Harness-Setup-2.0.0-x64.exe`. Установщик не
автоматический: он спросит папку установки, создаст ярлыки в меню «Пуск» и на рабочем столе.

Портативный вариант: распакуй `Comrade Harness-2.0.0-win-x64.zip` в любую папку и запусти
`Comrade Harness.exe`.

SmartScreen может предупредить о «неизвестном издателе» (подписи нет) — «Подробнее» →
«Выполнить в любом случае».

## Интернет

У модели три способа выйти в сеть, и она выбирает их сама:

- **`web_search`** — поиск в интернете (DuckDuckGo, при блокировке переключается на резервные
  источники). Возвращает заголовки, ссылки и выдержки.
- **`read_url`** — быстрое чтение страницы по HTTP без JavaScript: превращает HTML в аккуратный
  текст, забирает заголовок, описание и ссылки. Понимает PDF и JSON.
- **`browser`** — настоящий Chromium внутри приложения: выполняет JavaScript, хранит cookie и
  сессии, умеет кликать, печатать, скроллить и возвращаться назад. Нужен там, где сайт рисуется
  скриптами или требует входа.

Кнопка с глобусом в верхней панели открывает окно браузера агента: можно один раз войти в нужный
сервис руками, дальше агент пользуется этой же сессией. В настройках есть очистка cookie и данных
сайтов.

## Провайдеры и модели

Провайдер — это любой OpenAI-совместимый endpoint (`.../chat/completions`) со списком моделей.
У одного провайдера может быть сколько угодно моделей: они показываются чипами и в переключателе
моделей с поиском.

Поля провайдера:

- **Название** — как он будет выглядеть в интерфейсе.
- **API URL** — адрес вида `https://api.deepseek.com/chat/completions`.
- **API-ключ** — уходит в заголовке `Authorization: Bearer …`.
- **Модели** — по одной в строке; можно задать своё имя через `id = Отображаемое имя`.
- **Доп. заголовки** — JSON (например `{"HTTP-Referer": "..."}` для OpenRouter).

Стриминг включён всегда: текст и размышления появляются по мере генерации. Если провайдер не
поддерживает какой-то параметр, агент автоматически повторяет запрос в упрощённом виде, а при
ошибках `429/5xx` делает до двух повторов.

## MCP (Model Context Protocol)

Раздел «Плагины» → вкладка «MCP». Есть готовые пресеты: демо-сервер (встроенный, для проверки),
filesystem, fetch, github, brave-search, puppeteer, memory, sequential-thinking, notion, slack,
sqlite. Можно добавить и свой сервер:

- **stdio** — команда и аргументы, например `npx -y @modelcontextprotocol/server-filesystem /Users/me`;
  переменные окружения задаются строками `KEY=значение`.
- **HTTP** — URL сервера и произвольные заголовки.

После запуска инструменты сервера появляются в общем списке как `mcp_<сервер>_<инструмент>` и
становятся доступны модели (счётчик инструментов есть в верхней панели). Статус, список
инструментов и текст ошибок видны на карточке сервера.

## Сервисы (коннекторы)

Раздел «Плагины» → «Сервисы». Коннектор — это декларативный манифест: как авторизоваться и какие
инструменты дать агенту. Пользователь логинится один раз, дальше агент работает от его имени.

| Сервис | Авторизация | Что нужно |
| --- | --- | --- |
| GitHub | токен | Personal access token (scopes: `repo`, `read:user`, `workflow`) |
| Notion | токен | Internal integration token; страницу нужно расшарить на интеграцию |
| Slack | токен | Bot/user token (`chat:write`, `channels:read`, `search:read`) |
| Google Drive | OAuth 2.0 | свой OAuth Client ID (тип Desktop) в Google Cloud |
| Gmail | OAuth 2.0 | тот же Client ID, scopes Gmail |
| Linear | токен | API key из настроек Linear |
| Jira | basic | адрес сайта (`team.atlassian.net`), email и API-токен |

OAuth выполняется по схеме authorization code + PKCE, редирект идёт на `127.0.0.1` (loopback),
токен обновляется автоматически. У коннектора есть выключатель: можно отключить инструменты, не
удаляя авторизацию.

Свой коннектор можно положить файлом в
`~/Library/Application Support/comrade-harness/connectors/` (macOS) — он появится в списке после
«Обновить». Формат — JSON-манифест с блоками `auth` и `tools` (см. примеры в `plugins/connectors/`).

Токены шифруются через Keychain/DPAPI (`safeStorage`) и лежат в `comrade-secrets.json`; рядом
`comrade-config.json` с настройками рабочей папки, агента и MCP-серверов.

## Тесты

```bash
npm run probe    # интеграционная проверка интерфейса и агента (33 пункта)
npm run smoke    # быстрый запуск со скриншотами интерфейса (.cache/smoke-*.png)

# проверка содержимого собранного приложения
ELECTRON_RUN_AS_NODE=1 "dist/mac-arm64/Comrade Harness.app/Contents/MacOS/Comrade Harness" \
  test/verify-package.js "$PWD/dist/mac-arm64/Comrade Harness.app"
```

`npm run probe` поднимает локальный «фейковый» OpenAI-совместимый сервер и проверяет реальный
цикл агента: стриминг, размышления, вызовы инструментов, браузер с JavaScript, MCP-сервер,
коннектор и отрисовку чата (в том числе то, что ответ ассистента идёт без пузыря).

## Структура

```
main.js               главный процесс: окно, IPC, жизненный цикл
preload.js            мост contextBridge (window.comrade)
renderer.js           интерфейс: чат, провайдеры, плагины, настройки
index.html/style.css  разметка и оформление
lib/agent.js          цикл агента, SSE-стриминг, вызовы инструментов
lib/tools.js          реестр инструментов (файлы, сеть, браузер, MCP, коннекторы)
lib/web.js            поиск и чтение страниц
lib/browser.js        скрытый Chromium для агента
lib/mcp/              клиент и менеджер MCP
lib/connectors/       коннекторы сервисов и OAuth
plugins/connectors/   манифесты сервисов
plugins/mcp/          встроенный демо-MCP-сервер
vendor/               marked (markdown), локальные шрифты
```

## Ограничения

- Сборки не подписаны и не нотаризованы: macOS и Windows предупредят при первом запуске.
- Сборки не подписаны сертификатами: macOS — ad-hoc подпись (запускается, но Gatekeeper
  предупреждает), Windows — без подписи (SmartScreen предупреждает).
- Собраны macOS arm64 и Windows x64. Для Intel-мака нужен `electron-builder --mac --x64`.
- Инструменты `read_url` и `web_search` не выполняют JavaScript — для таких сайтов есть `browser`.
